#Equipo 5 Proyecto 1 - Ecommerce
# README
1. Ramas: Nadie sube nada a main. Se trabaja en ramas con el nombre de la tarea (ej: feature-navbar).
2. Imágenes: Establecer un peso máximo (ej: no subir imágenes de 5MB, pasarlas por un compresor antes).
3. Clases de Bootstrap: Acordar el uso de contenedores (container o container-fluid) para que el ancho de la página sea consistente en todas las vistas.
4. Pull Requests: Todo código debe ser revisado antes de integrarse a la rama principal
5. Trello: Es obligatorio actualizar el estado de las tareas (Backlog, In Progress, Review, Done) para evitar duplicidad de trabajo.
6. Responsive: Todos los componentes deben ser probados en resoluciones móviles (375px), tablet (768px) y desktop (1024px+).
